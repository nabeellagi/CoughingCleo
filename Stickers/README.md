# Welcome Stickers Folder
Here you will see all files related to stickers

1. If you want to see where to place the stickers then you can see the images inside the placement_guide folder.
2. If you want to be able to adjust or edit the stickers itself then feel free to modify the .ipv files inside ibis_files folder
3. The full exported image is provided inside render folder
4. To open layout.svg please use **Inkscape** to be able to change or modify the layout.
